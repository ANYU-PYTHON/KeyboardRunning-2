## 動作方法
このリポジトリをダウンロードしたうえで、Python環境にPygameが入ってることを確認し、*KeyboardRunning2.py*を実行してください。
*defs.py*は実行しないでください。<br>
また、*all_points.pkl*が存在しない場合、ランキング保存のため自動で生成されます。<br>
再起動時にランキングデータを引き継ぎたくない場合、*all_points.pkl*を削除してください。
